공유받은 배치입니다. 내 저장본은 그대로 있습니다.
상품 페이지 열기

가구를 누르면 방 가운데에 놓여요. 놓은 가구를 누르면 바로 위에 회전, 복제, 치수, 삭제 버튼이 떠요. 치수는 흔한 기본값이니 '치수'를 눌러 실제 값으로 고쳐 주세요. 배치는 이 폰에 자동 저장되고, 다른 기기나 다른 사람에게는 '공유'로 보내요.

쇼핑몰 상품 페이지의 치수를 보고 직접 입력하세요. 링크는 공유 링크에 같이 저장됩니다.

방에 놓은 가구가 자동으로 모입니다. 가격은 가구를 눌러 선택한 뒤 직접 입력하세요. 합계는 입력한 가격만 더한 값이라 실제 구매가와 다를 수 있습니다.

사진 위 배치: 사진을 올린 뒤 바닥의 네 모서리를 먼쪽 왼쪽 → 먼쪽 오른쪽 → 가까운쪽 오른쪽 → 가까운쪽 왼쪽 순서로 탭하세요. 먼쪽 벽 길이를 방 가로에, 옆 벽 길이를 방 세로에 입력해야 합니다. 가구가 사진 속에서 기울어져 보이면 원근 보정을 조절하세요. 사진은 이 기기에만 저장되고 공유 링크에는 들어가지 않습니다. 현재는 직사각형 방만 지원합니다.
